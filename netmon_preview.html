📖 راهنمای کاربر — NETWORK MONITOR v3.4

هر تب یک ابزار مستقل است؛ با یک نگاه ببینید هر کدام چه کاری انجام می‌دهد و چطور از نتیجه استفاده کنید:

  • 🖥 داشبورد — سرعت لحظه‌ای دانلود/آپلود، لیست فرآیندهای پرمصرف (کلیک راست = بستن/نمودار/فایروال)، اتصالات فعال با سطح ریسک امنیتی و نمودار زنده پهنای باند. نقطه شروع برنامه.
  • 📈 تاریخچه — نمودار پهنای باند ۲۴ ساعت اخیر + آمار پینگ. دکمه 📄 Daily Report یک گزارش کامل HTML/PDF از امروز می‌سازد.
  • 📊 آداپتورها — مشخصات کامل کارت شبکه (سرعت، IP، MAC) و خلاصه سیستم. برای تشخیص «چرا اینترنت کند است» اول اینجا را ببینید.
  • ⚡ تست سرعت — پینگ، جیتر، دانلود و آپلود واقعی. پینگ زیر ۳۰ عالی، زیر ۸۰ خوب است؛ جیتر بالا = اتصال لرزان.
  • 🗺 موقعیت‌یاب — کشور، شهر و ISP هر IP یا دامنه + نمایش روی نقشه. از داشبورد هم با کلیک راست روی اتصال قابل دسترسی است.
  • 📡 پایشگر پینگ — نمودار زنده ۴۰ نمونه آخر؛ خط صاف = پایدار، نقطه قرمز = بسته ازدست‌رفته (Packet Loss).
  • 🛡 اسکنر پورت — پورت‌های باز روی یک سرور (بازه: 20-1024 یا لیست: 80,443). فقط روی سرور خودتان!
  • 🔍 ابزارهای DNS — تبدیل دامنه↔IP و مقایسه سرعت سرورهای DNS مختلف با رنگ‌بندی سبز/قرمز.
  • 🔧 تنظیم DNS — تغییر DNS سیستم برای باز شدن سریع‌تر سایت‌ها + بازگشت به DHCP و پاک‌سازی کش. نیازمند ادمین.
  • 🔎 اسکنر IP — پیدا کردن همه دستگاه‌های متصل به شبکه محلی (مثل 192.168.1.0/24). برای کشف دستگاه‌های ناشناس عالی است.
  • 🚀 گیم بوست — اولویت‌بندی QoS ترافیک بازی + اولویت CPU + فایروال برای کاهش لگ (فقط ویندوز، نیازمند ادمین).
  • 🎮 سرورهای بازی — پینگ زنده سرورهای محبوب + اضافه کردن سرور سفارشی برای انتخاب بهترین گزینه.
  • 🤖 اتوماسیون — قوانین شرطی مثل «اگر پینگ بالا رفت، DNS گیمینگ فعال کن» که خودکار اجرا می‌شوند.
  • ⚙️ خروجی کانفیگ — پیکربندی خام شبکه (ipconfig/ifconfig) برای عیب‌یابی عمیق.

میانبرها: Ctrl+R رفرش · Ctrl+E خروجی CSV · Ctrl+P توقف · Ctrl+K بستن فرآیند. بستن پنجره = رفتن به سینی سیستم؛ خروج کامل از منوی سینی.
